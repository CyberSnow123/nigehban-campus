# Data Contracts

> The single source of truth for every shape that crosses a boundary (cv → api → db → web). Change this file **before** changing code. Code lives in `packages/contracts/nigehban_contracts/` (Pydantic). Web TS types are generated from the API's OpenAPI schema and are never hand-written.

## 1. Conventions
- **JSON casing:** `snake_case` everywhere (Python, DB, API, generated TS).
- **IDs:** `<prefix>_<ULID>`, generated server-side except `evt_` (generated by cv so retries are idempotent).

  | Prefix | Entity | | Prefix | Entity |
  |---|---|---|---|---|
  | `evt_` | DetectionEvent | | `run_` | Run |
  | `alt_` | Alert | | `cam_` | Camera |
  | `act_` | AlertAction | | `usr_` | User |

- **Human reference:** `ref_code` = `SEC-<YYYY>-<NNN>-<A|T>` (A = abandoned, T = theft), e.g. `SEC-2026-004-T`.
- **Time:** `occurred_at` and all `*_at` are UTC ISO-8601. `video_ts_s` is seconds from the start of the video. **Detection logic uses video time only, never wall-clock time.**
- **Boxes:** `bbox = [x1, y1, x2, y2]` in pixels of the source frame.
- **Track IDs:** ByteTrack integers. They are unique **within one run only**. "Person #12" in the UI means `track_id 12` in that run.
- **Versioning:** every event carries `schema_version` (currently `1`).

## 2. Enums
| Enum | Values |
|---|---|
| `EventType` | `abandoned_bag`, `possible_theft` |
| `BagClass` | `handbag`, `backpack` |
| `EventSource` | `real`, `mock` |
| `AlertStatus` | `active`, `acknowledged`, `resolved`, `false_alarm`, `authorised_pickup`, `confirmed_theft` |
| `RunStatus` | `queued`, `running`, `completed`, `stopped`, `failed` |
| `UserRole` | `operator`, `admin` |

**Alert status transitions** (all others are rejected with `409 INVALID_TRANSITION`):
```
active ──acknowledge──▶ acknowledged
active | acknowledged ──close──▶ resolved | false_alarm                       (any type)
active | acknowledged ──close──▶ authorised_pickup | confirmed_theft          (possible_theft only)
```
`active` and `acknowledged` are "open". All other statuses are "closed".

## 3. DetectionEvent (cv → api)
Sent as `multipart/form-data` to `POST /api/ingest/events` with the fields `event` (JSON below) and `snapshot` (JPEG, max 2 MB).
```json
{
  "schema_version": 1,
  "event_id": "evt_01JD2X…",
  "type": "possible_theft",
  "run_id": "run_01JD2W…",
  "camera_id": "cam_01JD2V…",
  "source": "real",
  "occurred_at": "2026-11-22T14:47:05Z",
  "video_ts_s": 125.4,
  "bag": { "track_id": 18, "class": "handbag", "bbox": [812, 440, 905, 560] },
  "owner_track_id": 2,
  "carrier_track_id": 12,
  "separation_s": null,
  "owner_distance_m": 3.1,
  "owner_away_s": 35.0,
  "confidence": 0.94,
  "owner_match": 0.18
}
```
| Field | Rule |
|---|---|
| `owner_track_id` | nullable: unknown owner |
| `carrier_track_id`, `owner_away_s`, `owner_match` | `possible_theft` only, else `null` |
| `separation_s` | `abandoned_bag` only, else `null` |
| `owner_distance_m` | nullable: estimate, may be pixel-derived |
| `confidence`, `owner_match` | 0–1 |
| `is_demo` | **not sent**. The API derives it as `source == "mock"` (D-06) |

Response `201 {"alert_id": "alt_…", "duplicate": false}`. A resent `event_id` returns `200` with `duplicate: true` and creates nothing.

## 4. Run telemetry (cv → api)
- `POST /api/ingest/runs/{run_id}/status`: `{"status": "running", "frames_processed": 3120, "fps": 14.2, "message": null}`
- `POST /api/ingest/runs/{run_id}/frame`: multipart `frame` (JPEG, latest annotated frame, at most 1 per second). It overwrites the previous frame.

## 5. API read models (api → web)
**Alert**
```json
{
  "id": "alt_…", "ref_code": "SEC-2026-004-T", "type": "possible_theft", "status": "active",
  "is_demo": false,
  "camera": { "id": "cam_…", "name": "CAM 03", "location": "Student Affairs Office" },
  "run_id": "run_…", "event_id": "evt_…",
  "occurred_at": "…", "video_ts_s": 125.4,
  "bag": { "track_id": 18, "class": "handbag", "bbox": [812, 440, 905, 560] },
  "owner_track_id": 2, "carrier_track_id": 12,
  "separation_s": null, "owner_distance_m": 3.1, "owner_away_s": 35.0,
  "confidence": 0.94, "owner_match": 0.18,
  "snapshot_url": "/api/alerts/alt_…/snapshot",
  "acknowledged_by": null, "acknowledged_at": null, "closed_at": null,
  "created_at": "…"
}
```
**AlertAction**: `{ "id": "act_…", "alert_id": "alt_…", "action": "acknowledge|close", "from_status": "active", "to_status": "acknowledged", "user": {"id","display_name"}, "note": null, "at": "…" }`

**Run**: `{ "id", "camera_id", "source", "video_path", "status", "is_demo", "frames_processed", "fps", "started_at", "ended_at", "message" }`

**Camera**: `{ "id", "name", "location", "is_active" }`

**User (me)**: `{ "id", "username", "display_name", "role" }`

**Stats** (dashboard): `{ "open_total", "active", "acknowledged", "today_abandoned", "today_theft", "closed_today", "running_runs" }`

## 6. Common API shapes
- **Page:** `{ "items": [...], "total": 42, "page": 1, "page_size": 20 }`
- **Error:** `{ "error": { "code": "INVALID_TRANSITION", "message": "Human-readable text." } }`. No stack traces and no file paths.
- **Error codes:** `UNAUTHORIZED`, `FORBIDDEN`, `NOT_FOUND`, `VALIDATION_ERROR`, `INVALID_TRANSITION`, `DUPLICATE_EVENT`, `RUN_NOT_RUNNING`, `INTERNAL_ERROR`.
- **Close request:** `{ "outcome": "false_alarm", "note": "Owner returned" }`

## 7. `config.json` (cv worker)
```json
{
  "classes": ["person", "handbag", "backpack"],
  "detector": { "weights": "yolo26n.pt", "conf": 0.35, "imgsz": 960, "device": "auto" },
  "tracker": { "type": "bytetrack", "track_buffer": 60 },
  "association": { "near_ratio": 1.0, "min_frames": 30 },
  "abandon": { "away_ratio": 2.5, "threshold_s": 60 },
  "theft": { "min_displacement_ratio": 1.5, "min_frames": 15, "owner_match_threshold": 0.6 },
  "output": { "annotated_video": true, "events_csv": true, "frame_push_interval_s": 1.0 },
  "api": { "base_url": "http://localhost:8000", "api_key_env": "NIGEHBAN_WORKER_KEY" }
}
```
Distance ratios are relative to the person's box height, so they adjust for perspective. Unknown keys cause an error, and missing keys fall back to the defaults shown.

|---|---|
